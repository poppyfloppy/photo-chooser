# photo-chooser

CLI для macOS 26: по альбому Photos и темам поездки собирает посты для Instagram — на тему карусель ленты до 5 кадров с запасными ракурсами и до 9 stories — и копирует их оригиналы в отдельную папку. Медиатека Photos не меняется. Требования — в [SPEC.md](SPEC.md).

## Установка и доступ

```bash
uv sync
```

Приложению нужен только доступ **Photos**: System Settings → Privacy & Security → Photos → включите Terminal (полный доступ). Full Disk Access не нужен. Первый запуск из Terminal покажет системный запрос.

Для облачных ступеней нужен ключ Claude API: `ANTHROPIC_API_KEY` в окружении или профиль `ant auth login`. С `--no-cloud` ключ не нужен.

## Команды

```bash
uv run photo-chooser albums                       # альбомы Photos с числом фото
uv run photo-chooser run trip.yaml                # все темы файла поездки
uv run photo-chooser run trip.yaml --dry-run      # только локальные этапы и оценка стоимости
uv run photo-chooser run trip.yaml --no-cloud     # без Claude, бесплатно: отладка механики
uv run photo-chooser run trip.yaml --model claude-sonnet-5-5   # модель второй ступени на этот запуск
uv run photo-chooser run trip.yaml --max-cost 8   # разово поднять лимит бюджета альбома
uv run photo-chooser style                        # построить профиль стиля страницы Instagram
uv run photo-chooser run --album "Египет 2026" --theme "Гиза" --query "пирамиды, сфинкс" \
    --from "2026-03-12 06:00" --to "2026-03-12 14:00" --timezone Africa/Cairo
```

Во время `run` видно, что происходит: группы первой и второй ступени, сборка постов по каждой теме, итог по постам. Если модель отвечает дольше 30 секунд, раз в 30 секунд выводится «ждём ответ модели (1:30)»; без ответа 5 минут запрос повторяется — это тоже видно. Прерванный по Ctrl+C запуск продолжается с оплаченного: ответы уже в кэше.

Коды выхода: 0 — успех, 1 — ошибка (в том числе не обработана одна из тем), 2 — конфигурация, 3 — бюджет, 4 — альбом не найден или неоднозначен, 5 — нет доступа к Photos.

## Файл поездки

```yaml
album: "Египет 2026"
timezone: Africa/Cairo        # обязателен, если у какой-либо темы есть интервал
themes:
  - name: Гиза
    query: "пирамиды, сфинкс, верблюды на фоне пирамид"
  - name: Абу-Симбел
    query: "храм с колоссами Рамзеса"
    from: 2026-03-14 05:00    # местное время поездки
    to:   2026-03-14 12:00
  - name: День 3              # только интервал: все кадры дня, ранжирование по качеству
    from: 2026-03-15 00:00
    to:   2026-03-15 23:59
```

Как формулировать темы:

- Темы с `query` оцениваются вместе, поэтому тема может ссылаться на другие: «оставшиеся храмы» — храмы, не вошедшие в остальные темы.
- Расшифровывайте аббревиатуры и неоднозначные названия: «GEM (Большой Египетский музей)», «Карнакский храм», а не «Карнакский музей». Формулировка влияет на отбор сильнее, чем выбор модели.
- Близкие по смыслу темы (маска Тутанхамуна в GEM и Долина Царей) лучше развести словами или интервалом. Кадр может попасть в несколько тем.

## Результат

На каждую тему — посты: карусель для ленты (до 5 кадров, первый — обложка) с запасными ракурсами к каждому кадру и до 9 stories. Карусель собирает модель из сильнейшего сюжета темы и выбирает порядок; следующие по силе кадры, в том числе другой сюжет темы, и «интересное» с подсказкой, что пояснить, уходят в stories — в порядке съёмки. Портрет поднимает оценку и может стать обложкой, только если кадр гармоничен: человек небольшой на фоне места и видны масштаб и перспектива, или это настоящий портрет с боке и красивым светом; кадры со срезанными ногами или неловкой позой пропускаются. Автора от спутника программа не отличает. Лучше меньше, но качественно.

```
~/Pictures/photo-chooser/<альбом>/<YYYY-MM-DD_HHMM>/<тема>/
  feed/carousel-1 Пирамиды и Сфинкс/01_IMG_4521.HEIC      ← обложка
  feed/carousel-1 Пирамиды и Сфинкс/02_IMG_4533.JPG
  feed/carousel-1 Пирамиды и Сфинкс/alternatives/01a_IMG_4519.HEIC
  stories/01_IMG_4610_live-frame.tiff                      ← stories по времени съёмки
  report.md
```

Каждый запуск пишет в новую директорию. Копируются оригиналы без правок Photos; у Live Photo — ключевой снимок или кадр видео в TIFF, если он явно лучше. Запасной ракурс `03a_…` можно поставить вместо кадра 03, не меняя карусель. В `report.md` — модели и версии промптов, по каждой карусели и stories таблица с оценкой (сила кадра 1–10), причиной и советом по кадрированию в 4:5 (лента) или 9:16 (stories), у «интересных» stories — что пояснить в тексте, сводка по этапам и стоимость.

## Настройки

`~/.config/photo-chooser/config.yaml` — необязателен, значения по умолчанию в [SPEC.md](SPEC.md) (FR-8) и [docs/spike-findings.md](docs/spike-findings.md). Например:

```yaml
posts: {carousels: 1, carousel_size: 5, stories: 9}
cloud:
  model: claude-opus-5-5         # вторая ступень и сборка постов
  max_cost_usd_per_album: 5.0    # на Opus тема стоит около $1
```

Кэш признаков, оценок и расходов — `~/Library/Caches/photo-chooser/`. Повторный запуск тех же тем на той же модели не платит за облако повторно.

## Стиль страницы

Чтобы отбор учитывал стиль вашей страницы Instagram, добавьте в `~/.config/photo-chooser/config.yaml`:

```yaml
style:
  albums: [Snapseed, Instasize]        # опубликованные посты; одноимённые альбомы берутся все
  screenshots_album: Instagram style   # скриншоты гридов и подборок stories
```

и постройте профиль:

```bash
uv run photo-chooser style
```

Команда выберет около 40 постов с 2018 года (свежие — чаще) и скриншоты страницы, покажет оценку стоимости (на `claude-opus-5-5` около $0.25) и после подтверждения запишет описание стиля в `~/.config/photo-chooser/style.md`. Его можно читать и править руками. Профиль и скриншоты из альбома уходят в каждый запрос второй ступени и сборки постов: первые два в альбоме — гриды ленты, следующие два — stories (порядок задаётся в Photos, число — `style.reference_feed` и `style.reference_stories`). Правка профиля пересчитывает вторую ступень и сборку постов, первая остаётся в кэше. Без `style.md` отбор идёт как раньше, с предупреждением в отчёте.

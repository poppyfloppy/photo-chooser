# Spike findings (Task 1)

- **Дата:** 2026-11-01
- **Медиатека:** macOS 26.6, «Оптимизация хранилища», альбом `Egypt.26` (2586 объектов: 2522 фото, 64 видео; 279 Live Photo; 3 скриншота; пар RAW нет), поездка 21–28.10.2026.
- **Скрипты:** `spike/` (одноразовые). Данные — `spike/out/` (не в git).

Значения из этого файла — источник истины для конфигурации по умолчанию и констант в плане.

## Доступ и чтение (PhotoKit)

| Поле | Значение |
|---|---|
| Доступ | Работает с разрешением только **Photos** (уровень ReadWrite запрашивается, изменяющие вызовы не используются). Разрешение получает процесс, из которого запущен скрипт: запуск пользователя через `!` в Claude или Terminal. Bash-инструмент Claude доступа не получает |
| `orientation_fields` | `pixelWidth` / `pixelHeight` уже учитывают поворот: совпали с ориентацией превью в 323 из 323 случаев. 89% снимков в альбоме вертикальные |
| `original_filename_source` | `PHAssetResource.originalFilename` ресурса типа `Photo` (1) |
| `live_video_resource_type` | `PairedVideo` (9), проверено: `IMG_7507.HEIC` + `IMG_7507.MOV` |
| Правленные снимки | Дополнительные ресурсы 5 (`FullSizePhoto`), 7 (данные правок), 10, 16; оригинал — по-прежнему тип 1 |
| RAW | Не проверено: в «Egypt.26» и «FUJIFILM X-T5» RAW нет. Решение пользователя: RAW вне MVP, копируется только основной ресурс (тип Photo) |

## Первая ступень (отбор по темам)

8 тем пользователя: «Пирамиды в Гиза», «GEM», «Абу Симбел», «Долина Царей и Храм Хатшепсут», «Карнакский музей и Люксорский Храм», «Нил», «Саккара и Дахшур», «Оставшиеся храмы». 201 превью (каждое второе, по всей поездке).

| Вариант | Стоимость | Результат |
|---|---|---|
| A: тема за темой, «при сомнении — да», Haiku medium | $0.25 (9 тем) | Низкая точность: «GEM» — 90 из 201 (почти всё пирамиды и храмы), «Оставшиеся храмы» — 184 |
| **B: все темы сразу + альбом + релевантность 1–10, Haiku medium** | **$0.031** (8 тем) | На глаз высокая точность; 10 кадров без темы — самолёт, дорога, отель |
| B, Haiku high | $0.034 | Как Haiku medium |
| B, Sonnet 5.5 low / medium | $0.50 / $0.50 | Точнее узнаёт места (Нил с ЛЭП, колоннада Саккары); буквально читает «Карнакский **музей**» и уводит Карнакский храм в «Оставшиеся храмы». Расхождение с Haiku medium — 21 из 201 кадра |

Решение пользователя: **вариант B, `screen_model = claude-haiku-5-5`, effort `medium`, `min_theme_relevance = 5`**.

Наблюдения:
- Формулировка темы влияет сильнее выбора модели («Карнакский музей», «GEM»).
- В выборке нет кадров из GEM. Маска и саркофаги Тутанхамуна в GEM по смыслу близки к теме Долины Царей — проверить на приёмке.
- Ни одного пропущенного id и ни одного `refusal` (110 запросов).

## 2. Прогоны

Все команды — в Terminal из корня репозитория, по порядку. Перед облачными прогонами `--dry-run` показывает число снимков по темам и оценку стоимости; ориентир на ~1000 снимков после отсева: первая ступень ~$0.15 один раз, вторая на тему — Haiku ~$0.02, Sonnet ~$0.35, Opus ~$0.8. Лимит альбома $5 на все прогоны вместе; поднимать `--max-cost` — только по решению пользователя.

```bash
uv run photo-chooser run docs/acceptance/egypt26.yaml --no-cloud
uv run photo-chooser run docs/acceptance/egypt26.yaml --dry-run
uv run photo-chooser run docs/acceptance/egypt26.yaml
uv run photo-chooser run docs/acceptance/egypt26.yaml --model claude-sonnet-5-5
uv run photo-chooser run docs/acceptance/egypt26.yaml --model claude-opus-5-5
```

Первый прогон читает превью всех снимков; на Egypt.26 (оригиналы на Mac) это ~1.5 мин, а не ~45, как ожидалось по spike. Повторные прогоны берут превью и признаки из кэша. Для замера NFR-4 повтора той же темы: повторить третью команду.

Замечания:

- Отсев «утилитарных» кадров Vision выбрасывал 197 из 2522 снимков — росписи гробниц, рельефы, экспонаты GEM. По решению пользователя флаг исключён из отсева (070fd67). После этого мусор — 14 кадров, пул — 971 снимок.
- Первый облачный прогон дважды падал с `KeyError: 'CGImageSourceCreateWithURL'`: гонка ленивой подгрузки pyobjc в потоках первой ступени, когда признаки уже в кэше. Исправлено в 2c17ae1.
- Один прогон 0.2 упал на `APIConnectionError` (сбой сети). Повтор прошёл, ничего не было оплачено дважды.
- Похожие ракурсы одной сцены в ленте пользователь считает полезными («чтобы выбор был»): правило «один кадр на сцену» не вводилось.
- Главная претензия к Haiku — граница между лентой и stories: часть кадров из stories пользователь поставил бы в ленту и наоборот. Sonnet и Opus переставляют 6–8 кадров на тему именно на этой границе.
- «Абу Симбел»: в интервале всего 59 снимков, отсюда недобор stories.

## 4. Решение

- Модель второй ступени (`cloud.model`): `claude-opus-5-5`. Первая ступень остаётся на `claude-haiku-5-5`.
- `cloud.effort`: `medium` (без отдельной калибровки).
- Почему: Sonnet раскладывает ленту и stories заметно лучше Haiku. Opus с ним в основном согласен (14–17 из 20); пользователь выбрал Opus после сравнения трёх лент рядом. Приоритет «качество > время > цена». Цена — ~$0.75 на тему из 100 кандидатов против ~$0.36 у Sonnet.
- Следствие для бюджета: при лимите $5 на альбом первая ступень (~$0.15) и вторая на Opus дают ~6 тем на альбом. Для поездок с большим числом тем лимит поднимается `--max-cost` или `cloud.max_cost_usd_per_album`.
- Вес соответствия стилю не калибровался: оставлен «наравне с композицией и светом» (FR-11.4).

Зафиксировано в `~/.config/photo-chooser/config.yaml`:

```yaml
cloud:
  model: claude-opus-5-5
  effort: medium
```

# Интеграционные тесты на реальной Photos

Тесты читают медиатеку Photos через PhotoKit, поэтому запускаются только из Terminal (или через `!` в чате Claude Code) — у процесса Claude доступа к Photos нет. По умолчанию `uv run pytest` их пропускает (маркер `integration`).

Что проверяется:

| Тест | Что проверяет |
|---|---|
| `test_library_unchanged_after_run` | NFR-1: после прогона с экспортом оригиналов у альбома тот же состав, те же даты изменения, флаги «избранное»/«скрытое», и не изменился список альбомов |
| `test_no_cloud_run_on_test_album` | FR-3–FR-6 без облака: скриншот не попал в шорт-лист, из серии — не больше одного кадра, Live Photo выгружено одним файлом, файлы пронумерованы, есть `report.md` |
| `test_haiku_run_on_test_album` | Облачный прогон одной темы на `claude-haiku-5-5`: в отчёте модели, версии промптов и стоимость > 0. Маркер `cloud`, нужен `ANTHROPIC_API_KEY`, стоимость — меньше цента |

## 1. Тестовый альбом (~30 фото, собирается вручную)

Создайте в Photos обычный альбом, например `photo-chooser-test` (File → New Album), и добавьте в него:

- **серию из 5 дублей** — 5 кадров одного сюжета, снятых подряд за несколько секунд (тест считает серией кадры с интервалом ≤ 10 с);
- **скриншот** (любой снимок экрана iPhone или Mac);
- **смазанный кадр** (снятый в движении);
- **Live Photo** (хотя бы одно);
- **кадры двух тем**, например 6–8 фото с кофе и 6–8 фото улиц;
- остальное — любые фото, снятые в разные моменты.

Часть снимков может быть только в iCloud («Оптимизация хранилища») — так проверяется загрузка превью и оригиналов.

## 2. Проверка NFR-5 (только доступ Photos)

В System Settings → Privacy & Security:

- **Photos** — Terminal включён (полный доступ, не «Ограниченный»);
- **Full Disk Access** — Terminal **выключен**.

Если Terminal ещё не получал доступ, первый запуск покажет системный запрос — разрешите.

## 3. Запуск

В Terminal, из корня репозитория:

```bash
PHOTO_CHOOSER_IT_ALBUM="photo-chooser-test" uv run pytest -m "integration and not cloud" -v
```

С облачным тестом (тратит меньше цента; ключ берётся из `ANTHROPIC_API_KEY`, тема — из `PHOTO_CHOOSER_IT_QUERY`, по умолчанию «кофе»):

```bash
PHOTO_CHOOSER_IT_ALBUM="photo-chooser-test" PHOTO_CHOOSER_IT_QUERY="кофе" uv run pytest -m integration -v
```

Ожидаемо: все тесты `PASSED`. Если упал `test_library_unchanged_after_run` на дате изменения — проверьте, не правили ли вы снимки во время прогона: Photos сам иногда обновляет снимки фоновым анализом; повторите запуск.

Результаты прогонов пишутся во временные директории pytest и в медиатеку не попадают.
